### 1.  The C source (`hello.c`)

```c
/* hello.c – a tiny C extension that exports a hello() function */

#include <Python.h>

/* The function that will be called from Python */
static PyObject *
hello(PyObject *self, PyObject *args)
{
    /* Return the string "Hello, world!" */
    return PyUnicode_FromString("Hello, world!");
}

/* Method table – maps Python names to C functions */
static PyMethodDef HelloMethods[] = {
    {"hello",  hello, METH_NOARGS, "Return a greeting."},
    {NULL, NULL, 0, NULL}          /* sentinel */
};

/* Module definition structure */
static struct PyModuleDef hellomodule = {
    PyModuleDef_HEAD_INIT,
    "hello",          /* name of the module */
    "A tiny example module written in C.",  /* module docstring */
    -1,               /* size of per-interpreter state of the module,
                         or -1 if the module keeps state in global variables */
    HelloMethods
};

/* Module initialization function – required for Python 3 */
PyMODINIT_FUNC
PyInit_hello(void)
{
    return PyModule_Create(&hellomodule);
}
```

---

### 2.  The build script (`setup.py`)

```python
# setup.py – build script for the hello extension

from setuptools import setup, Extension
import sys
import os

# ------------------------------------------------------------------
# Helper: read the long description from README.md (optional)
# ------------------------------------------------------------------
def read_long_description():
    here = os.path.abspath(os.path.dirname(__file__))
    readme_path = os.path.join(here, "README.md")
    if os.path.exists(readme_path):
        with open(readme_path, encoding="utf-8") as f:
            return f.read()
    return ""

# ------------------------------------------------------------------
# Extension definition
# ------------------------------------------------------------------
hello_extension = Extension(
    name="hello",          # module name
    sources=["hello.c"],   # source files
    # If you need to link against libraries or add include dirs,
    # you can add them here.  For this simple example we don't.
)

# ------------------------------------------------------------------
# Setup() call – this is what setuptools runs when you invoke
# `python setup.py build` or `python setup.py bdist_wheel`
# ------------------------------------------------------------------
setup(
    name="hello",
    version="0.1.0",
    description="A tiny example C extension that says hello.",
    long_description=read_long_description(),
    long_description_content_type="text/markdown",
    author="Your Name",
    author_email="you@example.com",
    url="https://github.com/yourname/hello",
    license="MIT",
    packages=[],  # no pure‑Python packages – only the extension
    ext_modules=[hello_extension],
    classifiers=[
        "Programming Language :: Python :: 3",
        "Programming Language :: C",
        "License :: OSI Approved :: MIT License",
        "Operating System :: OS Independent",
    ],
    python_requires=">=3.6",
)
```

> **Why `setup.py`?**  
> `setuptools` is the de‑facto standard for packaging Python code.  
> The `Extension` object tells it that we want to compile a C module.  
> When you run `python setup.py bdist_wheel`, setuptools will:
> 1.  Compile `hello.c` into a shared object (`hello.cpython‑<py‑ver>-<platform>.so`).
> 2.  Bundle that object together with the package metadata into a `.whl`
>     file that can be installed with `pip`.

---

### 3.  Building the wheel

Open a terminal, navigate to the directory that contains `setup.py` and
`hello.c`, and run:

```bash
# 1. Build a wheel (creates a .whl file in the dist/ directory)
python setup.py bdist_wheel
```

You should see output similar to:

```
running bdist_wheel
running build
running build_ext
building 'hello' extension
creating build/temp.linux-x86_64-3.10
...
creating build/lib.linux-x86_64-3.10
creating build/lib.linux-x86_64-3.10/hello
...
creating dist
creating dist/hello-0.1.0-py3-none-any.whl
```

The resulting wheel file (`hello‑0.1.0‑py3‑none‑any.whl`) is a ready‑to‑install
binary distribution.

---

### 4.  Installing the wheel locally

You can install the wheel you just built with `pip`:

```bash
# Install the wheel from the dist/ directory
pip install dist/hello-0.1.0-py3-none-any.whl
```

> **Tip:**  
> If you want to test the installation without uploading to PyPI,
> you can install directly from the local wheel file as shown above.

---

### 5.  Using the installed module

Open a Python REPL (or write a small script) and import the module:

```python
>>> import hello
>>> hello.hello()
'Hello, world!'
```

If you want to run the module as a script, you can add a small
`__main__` block to `hello.c` or create a separate Python file that
imports the extension and calls `hello()`.
