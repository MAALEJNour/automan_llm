**Solution Explanation**

For every test case we are given

* `N` – number of students in the class  
* `M` – number of students that are already present  
* `K` – number of students that are still absent

The students are numbered from `1` to `N`.  
The `M` present students are given in the next line, the `K` absent students in the
following line.

For each test case we have to output the numbers of the students that are
present, in increasing order.



--------------------------------------------------------------------

#### Algorithm
For one test case

```
read N, M, K
present = empty set
repeat M times
        read x
        insert x into present
repeat K times
        read x          // absent student, ignore
output all elements of present in ascending order
```

The set guarantees that each present student is stored only once and that
the final output is automatically sorted.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the set of present students
in increasing order.

*Lemma 1*  
After reading the `M` numbers of present students, the set `present`
contains exactly those `M` numbers and no others.

*Proof.*  
Each of the `M` numbers is inserted once into the set.
No other numbers are inserted before this point.  
∎



*Lemma 2*  
After reading the `K` numbers of absent students, the set `present`
is unchanged.

*Proof.*  
The algorithm only reads the `K` numbers and performs no operation on
the set.  
∎



*Lemma 3*  
The final output consists of all elements of `present` in ascending order.

*Proof.*  
The set data structure stores its elements sorted.
The algorithm iterates over the set and prints each element once,
therefore the output is exactly the sorted list of elements in `present`.  
∎



*Theorem*  
For each test case the algorithm outputs precisely the numbers of all
present students, sorted increasingly.

*Proof.*  
By Lemma&nbsp;1, after reading the present students the set contains
exactly those students.  
By Lemma&nbsp;2, reading the absent students does not change the set.  
By Lemma&nbsp;3, the algorithm outputs all elements of the set in sorted
order.  
Thus the output is exactly the required list of present students.  
∎



--------------------------------------------------------------------

#### Complexity Analysis

Let `N` be the number of students in a test case.

* Inserting the `M` present students into a set costs  
  `O(M log M)` in the worst case (balanced binary tree implementation).
* Reading the `K` absent students costs `O(K)`.
* Printing the `M` present students costs `O(M)`.

Since `M + K = N`, the total time per test case is  
`O(N log N)` and the memory consumption is `O(M)`.

    for _ in 0..t {
        let n: usize = it.next().unwrap().parse().unwrap(); // not used directly

            let x: usize = it.next().unwrap().parse().unwrap();

            let _x: usize = it.next().unwrap().parse().unwrap();

            if !first {

            print!("{}", id);
